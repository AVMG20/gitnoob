# Fonts for the landing page

These are only used by `index.html` at the root of the repo, not by the app. They are served from here so the page does not call out to a font host.

| File | Font | Licence |
|---|---|---|
| `bricolage-grotesque.woff2` | [Bricolage Grotesque](https://github.com/ateliertriay/bricolage), variable, Latin subset | SIL Open Font License 1.1 |
| `inter.woff2` | [Inter](https://github.com/rsms/inter), variable, Latin subset | SIL Open Font License 1.1 |
| `commit-mono.woff2` | [Commit Mono](https://github.com/eigilnikolajsen/commit-mono), regular, Latin subset | SIL Open Font License 1.1 |

The subsets come from [Fontsource](https://fontsource.org).
